# گزارش پروژه: ساخت دماسنج ساده با سنسور IM35 (Temperature Sensor with Arduino)

## ۱. مقدمه  
در این پروژه، یک **سنسور دمای آنالوگ** (مثل LM35) به آردوینو متصل شده است و دمای محیط را اندازه‌گیری می‌کند. سپس این دما به صورت عددی (به واحد سانتی‌گراد) در Serial Monitor نمایش داده می‌شود..

## ۳. قطعات مورد استفاده  
- برد آردوینو Uno  
- سنسور دمای LM35  
- برد برد (Breadboard)  
- سیم‌های جامپر (jumper wires)
.

## ۴. نحوه‌ی ساخت مدار  
- **سنسور LM35**:  
  - VCC → 5V آردوینو  
  - GND → GND آردوینو  
  - OUT → A0 (ورودی آنالوگ)
.

## ۵. کد برنامه (اسکچ):

```cpp
const int im35Pin = A0;   // تعریف پین A0 به عنوان ورودی سنسور

void setup() {
  Serial.begin(9600);   // شروع ارتباط سریال برای نمایش داده
}

void loop() {
  int sensorValue = analogRead(im35Pin);        // خواندن مقدار آنالوگ از سنسور (۰ تا ۱۰۲۳)

  float voltage = sensorValue * (5.0 / 1023.0); // محاسبه ولتاژ واقعی

  float temperature = voltage * 100;             // محاسبه دما (بر اساس مشخصات سنسور)

  Serial.print("Temp :");                         // نمایش متن
  Serial.print(temperature);                       // نمایش دما
  Serial.println(" C");                           // نمایش واحد

  delay(1000);  // تأخیر ۱ ثانیه برای ثبات نمایش
}
```

### توضیح کد:  
- `analogRead(im35Pin)` — مقدار آنالوگ را از سنسور می‌خواند (محدوده: ۰ تا ۱۰۲۳).  
- `voltage = sensorValue * (5.0 / 1023.0)` — محاسبه ولتاژ واقعی:
  - چون آردوینو از 5V به عنوان ولتاژ مرجع استفاده می‌کند، هر واحد ADC برابر با `5/1023 ≈ 0.00489V` است.
- `temperature = voltage * 100` — محاسبه دما:
  - سنسور IM35/LM35 به ازای هر ۱۰ میلی‌ولت، ۱ درجه سانتی‌گراد تغییر دما را نشان می‌دهد — بنابراین ضرب در ۱۰۰ انجام می‌شود.
- `Serial.print()` — دما را به صورت اعشاری و با واحد "C" نمایش می‌دهد.  
- `delay(1000)` — برای اینکه نمایش در Serial Monitor قابل خواندن باشد.

## ۶. نحوه‌ی کارکرد  
- پس از آپلود کد، سنسور شروع به اندازه‌گیری دما می‌کند.  
- دما به صورت عددی (به واحد سانتی‌گراد) در Serial Monitor نمایش داده می‌شود.  
- اگر دست خود را نزدیک سنسور بگیرید، دما افزایش می‌یابد.

## ۷. نتایج  
سنسور به درستی دما را اندازه‌گیری و نمایش می‌دهد و در هر ثانیه آنرا آپدیت میکند.
